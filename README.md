# Aetheria Multi-Launcher

เปิดเกม [Aetheria Online](https://www.aetheria-online.in.th/play) หลายจอพร้อมกัน แต่ละจอมีข้อมูลล็อกอินของตัวเอง (บัญชี Guest แยกกัน)
และคุมทุกจอจากหน้าเว็บเดียวที่ `http://localhost:4322`

ทำจากโปรเจกต์ Lumivara Multi-Launcher — ใช้งานแบบเดียวกัน และ **เปิดพร้อมกับ Lumivara ได้** (พอร์ตไม่ชนกัน)

## ทำอะไรได้บ้าง
- เปิด/ปิดแต่ละจอ, เปิดทั้งหมด, ปิดทั้งหมด, เปิดอัตโนมัติเมื่อเปิด launcher
- PiP (หน้าต่างเล็กลอยบนสุด), เต็มจอ, ซ่อน+ปิดเสียง, ปิดเสียง, รีเฟรช, เรียกหน้าต่างขึ้นมา
- จัดเรียงทุกจอให้พอดีหน้าจอ (เลือกจอภาพได้ถ้ามีหลายจอ)
- ตั้งชื่อจอ (เป็นชื่อหน้าต่างเกม), ลากเรียงลำดับ, + / − จำนวนจอ
- เกมเล่นต่อแม้ย่อหรือซ่อนหน้าต่าง · จำกัดเฟรมเรตตอนซ่อนเพื่อประหยัด CPU (⚙ ตั้งค่า)
- เกมแครช / ค้าง / เน็ตหลุด → โหลดใหม่เอง
- ดู RAM / CPU ของแต่ละจอ · สำรองข้อมูลจอ (คัดลอกเท่านั้น ไม่ลบ)
- เข้าสู่ระบบด้วย Google ได้ (เปิดหน้าล็อกอินในเบราว์เซอร์ปกติ เหมือนตัวทางการ)
- Automation: เลือกจอ แล้วกดปุ่มในเกมพร้อมกันหลายจอ (ใช้ได้แม้จอซ่อนอยู่)

## วิธีเปิด
ดับเบิลคลิก `Aetheria Launcher.lnk` (ไม่มีหน้าต่างดำ) หรือ `start.bat` แล้วหน้าเว็บจะเปิดเอง

## คีย์ลัด
- `Ctrl+Shift+G` ซ่อน / เรียกกลับทุกจอ (ใช้ได้แม้อยู่ในโปรแกรมอื่น — Lumivara ใช้ `Ctrl+Shift+H`)
- ในหน้าต่างเกม: `F5` รีเฟรช · `F8` ซ่อนจอนี้ · `F11` / `Alt+Enter` เต็มจอ · `Ctrl+Shift+P` PiP · `Esc` ออกจาก PiP/เต็มจอ · `Ctrl+Shift+I` เครื่องมือนักพัฒนา

## ข้อควรรู้
- ข้อมูลแต่ละจออยู่ใน `saved\InstanceN` — **ห้ามลบ** บัญชี Guest อยู่ในนั้น ลบแล้วตัวละครหาย
  (ในเกมมีปุ่ม "บัญชีชั่วคราว · ผูกบัญชี" ไว้ผูก Guest กับชื่อผู้ใช้/รหัสผ่าน — แนะนำให้ผูกไว้)
- เปิดเกมหลายจอด้วยบัญชีเดียวกันจะเตะกันเอง — แต่ละจอต้องใช้คนละบัญชี
- ตรวจกติกาของเกมเรื่องเล่นหลายบัญชี / ใช้ automation ก่อนใช้งาน
